# FreeCode VS Code Assistant

Integrate the FreeCode daemon into your Visual Studio Code workspace.

## Features

- **Sidebar Assistant**: Send intent prompts and refactor requests directly to a local model (via the FreeCode daemon and LM Studio).
- **Execution Modes**: Toggle between Chat, HITL, and Auto execution.
- **Console Log**: View execution logs and replies.
- **AST Edit Tester**: Perform symbol-aware code refactoring.
